# 《烽火营垒》初始化设计摘要

本文件是从当前仓库 `game.md` 需求中提炼出的项目初始化范围，方便后续开发者快速理解方向。

## 游戏方向

- 类型：2D / 2.5D 俯视角国风轻 RTS。
- 核心体验：采资源 → 造兵营 → 出兵 → 打架 → 摧毁敌方主营 → 胜利。
- 平台：Windows 10 / Windows 11。
- 目标分辨率：1920×1080，16:9。

## V0.1 只验证的内容

- 主菜单。
- 一张测试战斗地图。
- 玩家阵营“苍旗军”和敌方阵营“赤焰军”的视觉占位。
- 主营、资源点、少量单位、HUD 的占位布局。

## 当前不会在初始化阶段实现的内容

- 完整 RTS 逻辑。
- 真实采集、建造、训练、战斗、胜负结算。
- AI、寻路、科技树、存档、联网、剧情、复杂美术和音效。

## 占位资源规则

当前所有临时资源都必须带有 `placeholder` 字样，后续替换为正式国风美术、UI 和音效资源。
